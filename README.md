# SalesCalculator
Консольное приложение на **.NET 10** для автоматизированной обработки Excel-отчётов, распределения позиций по категориям и расчёта итоговых таблиц.

## 📥 Скачать и запустить

Готовую сборку можно взять на странице [**Releases**](https://github.com/LinaKhatib/SalesCalculator/releases/latest).

1. Скачайте три файла: `SalesCalculator.exe`, `table.json`, `Positions.json`.
2. Положите их **в одну папку** (например, `C:\SalesCalculator\`).
3. Запустите `SalesCalculator.exe` (двойной клик).
4. Следуйте инструкциям в консоли:
   - введите путь к Excel-файлу с отчётом,
   - введите путь к `Positions.json`,
   - и др.

Результат будет сохранён рядом с исходным Excel-файлом с припиской `_Products`.


## ✨ Основные функции

*   **Автоматическая категоризация:** Считывает данные из Excel и сопоставляет позиции с категориями через JSON-словарь.
*   **Интерактивное обучение:** Если в Excel встречается новая позиция, программа предлагает пользователю выбрать категорию вручную и запоминает выбор в `Positions.json`.
*   **Очистка данных:** Автоматическое удаление лишних пробелов и конвертация строковых данных в числовые форматы для корректных расчетов.
*   **Генерация сложных формул:** Автоматически создает формулы `SUM` (СУММ) и арифметические зависимости в итоговых таблицах Excel.
*   **Динамическое сохранение:** Создает новый файл с суффиксом `_Products`, сохраняя оригинальный отчет нетронутым.

## 🛠 Технологии

*   **C# 12 / .NET 10**
*   **ClosedXML** — для глубокой работы с форматами Excel (.xlsx) в Excel Online
*   **Newtonsoft.Json** — для работы с конфигурационными файлами

## 🏗 Структура проекта

| Файл | Назначение |
|---|---|
| `table.json` | Конфигурация внешнего вида и структуры итоговой таблицы (цвета, шрифты, координаты) |
| `Positions.json` | Словарь-справочник «Позиция → Категория» |
| `ProcessExcelService.cs` | Сервис-координатор: открывает Excel, определяет порядок вызовов методов и сохраняет изменения в новый файл |
| `PositionCheckingService.cs` | Сервис проверки новых товаров и обновления словаря |
| `TableCreationService.cs` | Логика отрисовки таблиц и записи формул |


## 🔨 Настройка перед запуском

### Требования

- [.NET 10 SDK](https://dotnet.microsoft.com/download)

### Шаги

```bash
git clone https://github.com/LinaKhatib/SalesCalculator.git
cd SalesCalculator
dotnet build
dotnet run --project SalesCalculator
```

### Настройка перед запуском (для разработки)

1. Убедитесь, что файлы `table.json` и `Positions.json` находятся в папке проекта `SalesCalculator/`.
2. В свойствах этих файлов в Visual Studio должно быть установлено **«Копировать всегда»** (или **«Копировать, если новее»**).

## 💡 Использование

1. Запустите приложение.
2. Введите путь к Excel-файлу с отчётом.
3. Введите путь к `Positions.json` (если файл лежит рядом с `.exe`, можно ввести просто `Positions.json`).
4. Если будут другие инструкции, то следуйте им.
5. Результат будет сохранён в той же папке с припиской `_Products`.

> В репозитории прикреплён пример работы приложения в виде файла `Отчет_о_розничных_продажах_за_ноябрь_2023_пример_Report.xlsx`.
